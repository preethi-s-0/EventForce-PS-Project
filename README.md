# EventForce Management System

A Salesforce-based event management system developed as an academic team project to manage events, clients, vendors, venues and feedback.

## Features

* Event and Client Management
* Vendor and Venue Management
* Automated Reminders
* Cancellation Approval Process
* Venue Availability and Double-Booking Prevention
* Reports and Dashboards
* User Access Management

## Technology

* Salesforce
* Apex
* Salesforce Flow
* Salesforce Lightning
